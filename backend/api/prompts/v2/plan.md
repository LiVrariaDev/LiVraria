## きまり

- キーワードの組を2〜4組作る。1組は1〜2語で、すべての語を含む本が検索される
- 語は名詞だけにする。「おすすめ」「わかりやすい」「〜の本」のような修飾語は入れない（例: 「わかりやすい気候変動の本」ではなく「気候変動」）
- 組ごとに切り口を変える（テーマそのもの、関連する題材、ジャンル名など）
- 読む人が子どもなら「絵本」「児童書」などを組み合わせる。入門なら「入門」を組み合わせてもよい
- 避けたいもの（avoid）に当たる語は使わない
- うろ覚えの書名を探すときは、覚えている言葉や著者名をそのまま使う
- 参考事例は、ほかの図書館で似た相談に司書がどう答えたかの記録です。キーワードや分類の参考にしてよいが、事例に出てくる語をそのまま全部使う必要はない
